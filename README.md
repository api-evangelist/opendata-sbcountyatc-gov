# San Bernardino County ATC OpenData (opendata-sbcountyatc-gov)

San Bernardino County ATC OpenData is a county government open-data portal for United States running **CKAN**, exposing a standardized catalog API over ~8 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/opendata-sbcountyatc-gov/refs/heads/main/apis.yml)
